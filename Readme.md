# What & Why
I wanted an "ambient" calendar - something I would see on an empty workspace in my WM/compositor of choice.

# Building
You'll need [gtk4-layer-shell](https://github.com/wmww/gtk4-layer-shell). Grab the headers to compile against it too:
`sudo dnf install gtk4-layer-shell` (likely you already have it)
`sudo dnf install gtk4-layer-shell-devel`
